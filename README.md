# cherrytree-agent-v2

This product uses the **Panel** bottom and the **Original** highlight question. Ask about a passage once, and the answer stays in the card.

**This product:** [Open the interview](https://anikanb-32.github.io/cherrytree-agent-v2/)

**Final draft review:** [Open the working draft](https://anikanb-32.github.io/cherrytree-agent-v2/new-product/index.html?draft=1)

The interview is a front-end mock. Nothing you type is stored.

## Run it

```bash
nvm use 22      # or any Node >= 20
npm install
npm run dev     # http://localhost:3005
```
